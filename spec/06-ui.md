# 06 — UI

Visuals front and centre: one large hero view, the all-sky dome (ADR-0006),
that reacts to both the data and the sound. Effects and modulation are
secondary and live in tabs. Goal: unmistakably its own, not FabFilter-like,
not cookie-cutter.

## Visual identity
- **The palette is physics.** Only the aurora's emission colours on a deep
  night-sky ground. Each colour has a job; iridescence comes from blending
  them, never from extra hues.

  | Token | Hex | Meaning | Job |
  |---|---|---|---|
  | `--night` | `#05070D` | night-sky ground | background |
  | `--ink` | `#C9D3E6` | starlight | primary text, hairlines |
  | `--muted` | `#8A96AD` | — | labels, secondary text |
  | `--o-green` | `#5CF2A0` | O 557.7 nm, ~110 km | wavetable/curtain body, live state |
  | `--o-red` | `#FF6B6B` | O 630.0 nm, ~250 km | slow, high-altitude modulation, storm |
  | `--n-violet` | `#8F7BFF` | N₂⁺ 427.8 nm, ~100 km | shimmer and highs, Bz |
  | `--day-rim` | faint light blue | stylistic daytime | rim shimmer only |

  (Hexes from the Hero Concepts canvas; tune for contrast ≥ 4.5:1 on text.)
- **Two layers, two materials.** An *organic* layer (the aurora: soft,
  glowing, slow) and an *instrument* layer (hairline traces, small technical
  type, observatory readouts: station, coordinates, UT, Kp). Controls belong
  to the instrument layer and are drawn as thin lines (arcs, hairline faders),
  not chunky knobs.
- **Type:** Instrument Sans (UI) + JetBrains Mono (readouts), bundled with the
  plug-in (SIL OFL), never loaded from the network.
- **References:** historical observatory magnetograms (fine traces on paper
  strip charts), mission-control readouts, all-sky camera frames.

```
├───────────────────────────────────────┴─────────────────────────────────────┤

├─────────────────────────────────────────────────────────────────────────────┤
│ Sky · Sound · Motion · Space FX · Data · OSC      (tab content below)       │
└─────────────────────────────────────────────────────────────────────────────┘
```
- **Header readouts:** station code and coordinates, UT time, Kp, Bz, solar
  wind speed, autopilot state (LIVE / JOURNEY day and ×speed / FROZEN with
  timestamp).
- **Dome:** zenith centre, horizon rim, compass labels with magnetic north
  marked, faint elevation rings. The curtain is projected fisheye; rays
  converge at magnetic zenith (corona at onset). Sun glow below the horizon,
  moon with phase, bright stars. Output envelope → glow; Breath → a slow
  global swell. Toggles (Sky tab): day/night tracking, stars and moon,
  gradients only.
- **Magnetogram strip:** H at the station, last 24 h (Journey: the replayed
  day), hairline trace in `--o-green`, now-marker in `--o-red`, onsets ticked.
- **Macros:** 4–6 large hairline arcs (proposal: Storm, Breath, Glow, Space,
  Drift; `01-functional-spec.md` §6).
- **Tabs:** *Sky* (station, autopilot, Journey day and speed, sky toggles),
  *Sound* (harmony: root, scale, chord, Mood, Progression, Voicing, Detune,
  Drift, Transpose, Register; layers; raw-field level), *Motion* (LFOs,
  random walkers, env follower, 16-slot matrix, triggers), *Space FX* (Drive →
  Phaser → Chorus → Delay → Reverb → Limiter), *Data · OSC* (source status,
  last fetch, cache, credits, OSC target and rate).

## Interaction
- **Legible:** the event ticker says in words what changed the sound
  ("21:40 UT substorm onset → shift to E major").
- Hovering a mod source highlights its destinations, and vice versa.
- Drag a mod source onto any control → creates a matrix slot.
- Motion is slow, never flashing; `prefers-reduced-motion` calms the dome.
- Every visual target is smoothed (same "no sudden change" rule as sound).

## Rendering
- Dome = one WebGL shader; node arrays arrive as a small texture from
  `SkySnapshot` telemetry (30–60 Hz). Replaces the TP.2 ambient background.
- Instrument layer = DOM/SVG/canvas, redrawn only when its data changes
  (the POC redraws 12 canvases every frame: a known CPU cost to fix).
- GPU budget: render the dome below CSS resolution if needed, cap ~30–60 fps,
  pause when hidden.

## Mock first
The page runs in a normal browser with a mock backend (POC infrastructure in
`source/ui/`). The T1.2 Sky Model sketch *is* the first mock backend: it feeds
the dome from the 10 May 2024 replay before any C++ exists.

## Exit criteria (M6)
- Dome and instrument layer render in the browser mock and the plug-in.
- Every control maps to a parameter ID in `parameters.yaml` (check script to write).
- UI CPU cost measured per view and within budget; owner review notes written.
