# T1.2 — Sky Model sketch in the browser
**Milestone:** M1   **Depends on:** T1.1   **Branch:** feat/t1.2-sky-sketch

## Goal
Build the Sky Model of `spec/04-sky-model.md` as a plain-JS sketch that
replays a T1.1 day and renders the all-sky dome over CMO, so the owner can
tune how it looks before any C++ exists. The sketch exports golden traces
that the C++ port (M2) must match.

Why a browser sketch (the brief allowed "web or Python"): the UI is web, the
dome renders interactively, and `model.js` later becomes the UI's mock
backend. Owner may veto.

## Scope
- `prototype/sky/model.js`: pure, no DOM. `SkyModel` with `reset(seed)`,
  `step()` at 100 Hz of model time, `snapshot()` matching the `SkySnapshot`
  fields in `spec/03-architecture.md`. Seeded RNG (counter-based), so the same
  seed and track give the same trace. Shape the code so it ports 1:1 to C++.
  - Reservoir and substorm phases (§2.1), curtain chain N = 64 (§2.2),
    pulsations (§2.3), events (§2.4), assimilation incl. data-forced onsets (§3).
- `prototype/sky/observer.js`: CMO → geomagnetic frame → dome projection (§4).
- `prototype/sky/astro.js`: sun, moon (with phase), ~100 bright stars (§5).
- `prototype/sky/dome.js`: WebGL (fallback Canvas 2D) rendering of the dome:
  curtain with rays, colour by emission line, corona at magnetic zenith,
  stars, moon, horizon rim; palette from `spec/06-ui.md`.
- `prototype/sky/index.html` + `panel.js`: day picker (T1.1 days), play /
  pause / scrub, speed 1× … 1440×, seed; readouts (UT, phase, Kp, Bz, v);
  charts of coupling, energy, H measured vs model; sliders for the tuning
  constants (§7), with "copy constants" to paste into the spec.
- `prototype/sky/export-goldens.mjs`: runs the model headless in Node over
  10 May 2024 and writes `tests/golden/sky/2024-05-10.json` (1-min resolution:
  phase, energy, activity, oval latitude, brightness of 8 sampled nodes,
  onset times).
- Run with `python3 -m http.server -d prototype/sky` (tracks are fetched
  from `resources/sky/`; serve from the repo root if paths need it).

## Constraints
- No dependencies, no build step: ES modules, WebGL 1.
- Plausible and beautiful beats correct; every visual target smoothed.
- `model.js` never reads wall-clock time or `Math.random()`.

## Allowed paths
prototype/sky/**, tests/golden/sky/**, spec/04-sky-model.md (tuned constants,
answers to §8), spec/tasks/T1.2-*.

## Acceptance criteria
- [ ] The dome replays 10 May 2024 at any speed, with scrub and pause.
- [ ] Phases (quiet / growth / onset / recovery) are visible and labelled; the
      storm's CMO H bays appear as onsets near the right times.
- [ ] Quiet day: gentle motion, never dead, never alarming.
- [ ] A curtain overhead converges into a corona at magnetic zenith.
- [ ] Sun and moon positions within ~2° of a reference for CMO (spot-check 3 times; note the reference).
- [ ] Node check: same seed + same track → identical trace (a small Node test).
- [ ] Goldens exported for 10 May 2024.
- [ ] Owner has looked at it; tuned constants and answers to §8 written back to `spec/04-sky-model.md`.
