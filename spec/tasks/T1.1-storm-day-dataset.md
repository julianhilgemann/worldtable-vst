# T1.1 — Storm-day dataset (10–11 May 2024 + a quiet and a moderate day)
**Milestone:** M1   **Depends on:** —   **Branch:** feat/t1.1-storm-days

## Goal
Record the magnetosphere data the Sky Model prototype replays, and that later
becomes the bundled factory sky, the Journey presets and the test fixtures.
Verify the historical endpoints listed in `spec/02-data-sources.md`.

## Scope
- **Days** (UTC, 48 h each so a night over Alaska is always complete):
  1. `2024-05-10` → 2024-05-10T00:00Z – 2024-05-12T00:00Z: the "Gannon"
     storm (Kp 9), the reference day.
  2. A **quiet** day pair (Kp ≤ 2 throughout; e.g. an international quiet day).
  3. A **moderate** day pair with clear substorms over CMO's magnetic midnight
     (Kp 4–5, negative H bays at CMO). Pick 2 and 3 from the Kp record and
     write down why.
- **Per day, raw responses** (so parsers are tested on real formats):
  - `geomag_CMO.json`: USGS `geomag.usgs.gov/ws/data/`, `id=CMO`,
    `elements=H`, `sampling_period=60`, `starttime`/`endtime`.
  - `kp.json`: GFZ Potsdam Kp (definitive, 3-hourly) for the span.
  - `solarwind.json`: NASA OMNI 1-min (`OMNI_HRO_1MIN`; speed, density,
    Bz GSM, By GSM), e.g. via CDAWeb HAPI.
- **Per day, derived track** `track.json`: one 1-minute grid over the span,
  channels `h` (nT), `kp`, `v` (km/s), `n` (cm⁻³), `bz` (nT), `by` (nT);
  `null` for gaps (OMNI fill values → `null`); Kp stepped per 3 h interval.
  This is the prototype's input and the reference for the C++ `TrackBuilder`.
- **Manifest** `manifest.json` per day: span, source URLs, licence and credit
  line per source, retrieved-at, units, why this day.
- **Live fixtures for M5:** one current response each of SWPC
  `noaa-planetary-k-index.json`, `planetary_k_index_1m.json`,
  `plasma-1-day.json`, `mag-1-day.json` into `tests/fixtures/{kp,solarwind}/`.
- **Tool:** `tools/record_sky_day.py --day 2024-05-10 [--hours 48]`
  fetches, stores raw, builds the track, prints a sanity summary
  (max Kp, min Bz, max |ΔH| at CMO, % gaps). Python stdlib only.

## Allowed paths
tools/record_sky_day.py, resources/sky/**, tests/fixtures/kp/**,
tests/fixtures/solarwind/**, tests/fixtures/geomag/**, spec/02-data-sources.md
(status column and verified URLs), spec/tasks/T1.1-*.

## Acceptance criteria
- [ ] Three days under `resources/sky/<YYYY-MM-DD>/` with raw responses, `track.json`, `manifest.json`.
- [ ] 10 May 2024 sanity: Kp reaches ≥ 8+, Bz reaches ≤ −30 nT, CMO H deviates by ≥ 500 nT.
- [ ] Quiet day: max Kp ≤ 2; moderate day: at least two negative H bays at CMO.
- [ ] Every endpoint and licence verified; `02-data-sources.md` updated (exact URLs, status).
- [ ] Rerunning the tool reproduces the files byte for byte except `retrieved-at`.
- [ ] No new dependency (stdlib `urllib`, `json`).
- [ ] `resources/sky/` ≤ ~2 MB in total.
- [ ] SWPC live fixtures recorded.
