# T3.8 — Resonator bands: crossovers, tones, shift (engine)
**Milestone:** M3   **Depends on:** T3.7   **Branch:** feat/t3.8-resonator-bands
**Status:** draft, start when the owner says so.   **Read first:** `spec/09-ui-v2.md` §7, §9; `spec/05-sound-engine.md` §1, §3, §12, §14; mockup `#res`

Owner, 2026-11-13: "the resonators need to have a way of being tuned somehow separately"; "resonator
crossover frequencies that change the bands of colors … if dragged, one band gets elongated, while
the other one gets shorter."

## Goal
The four resonator bands (low, red, green, violet) share one pitch axis, divided by three
**crossovers** between a **floor** and a **ceiling**. Moving a crossover lengthens one band and
shortens its neighbour. Each band can also choose which chord tones it rings and be shifted
against the chord. 12-TET only (`00-vision` non-goal). This task is the engine and the
parameters; the display is T6.11.

## What exists
`dsp/Voicing`: `layerRange(layer, registerSemitones, spread)` gives fixed ranges (red 31–49,
green 50–74, violet 72–90 at Register 0, Spread 2); `layerSlots` gives fixed tone sets (red: root
and fifth; green: the chord; violet: the tones other than root and fifth); `nearestNote` folds a
pitch class into a range. `SkySound.cpp` voices a chord with them (line ~334). The low resonator
takes the chord's root (or the lowest held note) in the Sub or Bass octave (`low_octave`).
Register and Spread take effect only at the next chord change.

## Design
- **Parameters** (`parameters.yaml`, then `tools/gen_params.py`), group `bands`:
  | ID | Type | Range | Default | |
  |---|---|---|---|---|
  | `band_floor` | int (MIDI note) | 21 … 60 | 24 | lowest note of the low band |
  | `band_x1` | int | 28 … 84 | 36 | crossover low │ red |
  | `band_x2` | int | 33 … 96 | 50 | crossover red │ green |
  | `band_x3` | int | 38 … 103 | 73 | crossover green │ violet |
  | `band_ceiling` | int | 43 … 108 | 91 | first note above the violet band |
  | `band_blend` | float, st | 0 … 6 | 1.5 | how far neighbours reach into each other |
  | `red_tones`, `green_tones`, `violet_tones` | choice | Root, Root + fifth, Chord, Colours, All | Root + fifth, Chord, Colours | |
  | `red_shift`, `green_shift`, `violet_shift` | int, st | −12 … 12 | 0 | transpose the band against the chord |
  Band *k* spans notes [edge*ₖ*, edge*ₖ₊₁*). Minimum widths: low 12 st (so the root always has a
  place), the others 5 st. The engine enforces order and minimum widths whatever the host
  automates (clamp from the floor upward); the UI clamps while dragging.
  **Removed:** `register_semis`, `spread`, `low_octave` (moving all edges is Register; their
  spacing is Spread; the low band's place is Sub/Bass). Nothing has been released. State version
  bump; an older state loads with the band defaults.
- **Voicing** (`Voicing.h/.cpp`, header first): `BandEdges { floor, x1, x2, x3, ceiling; blend }`;
  `bandRange(BandEdges, Layer)` → `NoteRange` = the band's span widened by `round(blend)` on each
  inner side (never past the floor or ceiling); `bandSlots(Chord, TonesChoice, shiftSemitones)` →
  `Slots` (Root; Root + fifth; the chord padded as `layerSlots` green does; the colours with the
  same fallback as violet today; All = Chord). `layerRange` and `layerSlots` go when nothing calls them.
- **Low band:** the low resonator's note is the lowest note of the root's pitch class at or above
  `band_floor` (in Play mode: the lowest held note folded the same way). Its octave partial stays.
- **Applying a change:** a moved edge, tone choice or shift re-voices the current chord through the
  double-bank crossfade, the way a key change by hand does today, once the value has been still for
  300 ms (count it in ticks). No retune of ringing energy, no click. Play mode's voices keep their
  own partials; only the low note's folding follows the edges.
- **Telemetry:** `ChordState` already carries every voice's note per layer; add the five edges as
  they are applied, so the display can draw what the engine uses.
- **Goldens change on purpose.** The defaults give contiguous bands: red's floor moves from G1 (31)
  to C2 (36) and the low band takes C1–B1; green and violet keep 50–74 and 72–90 within the blend.
  Write the reason here and regenerate `tests/golden/sound`. Sky goldens must not change.
