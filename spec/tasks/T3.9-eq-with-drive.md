# T3.9 — The EQ: four bands with drive (engine)
**Milestone:** M3   **Depends on:** T3.7   **Branch:** feat/t3.9-eq-with-drive
**Status:** approved by the owner, 2026-11-13.   **Read first:** `spec/09-ui-v2.md` §3, §7, §9; `spec/05-sound-engine.md` §7, §15; mockup `#eq`, `drawEq`, `eqDb`

Owner, 2026-11-13: "instead of filter, maybe making it an EQ with bands and drives."

## Goal
One tone stage in place of the Filter and the Drive: four bands, each with its own gain and its
own drive, so a person can saturate only one part of the sound. The sky still opens the top. This
task is the engine and the parameters; the display is T6.14.

## What exists
`fx/Filter` (two TPT SVF stages; LP12, LP24, BP, HP; the cutoff glides in log frequency; the sky's
activity, slewed 2 s, opens it by up to 3 octaves × `flt_sky`) sits between the sources and
`Drive` (ADAA tanh with asymmetry), inside `dsp/Sources`, so the sky reaches it on the tick grid.
Parameters `flt_type`, `flt_cutoff`, `flt_reso`, `flt_sky`, `drive`. Telemetry `filterHz`.

## Design
- **Bands** (fixed kinds): 1 a low shelf, 2 and 3 bells, 4 a high cut at 12 dB per octave.
- **Parameters** (`parameters.yaml`, then `tools/gen_params.py`), group `eq`:
  | ID | Range | Default | |
  |---|---|---|---|
  | `eq1_freq` | 30 … 400 Hz, log | 110 | low shelf corner |
  | `eq1_gain` | −12 … +12 dB | 0 | |
  | `eq2_freq`, `eq3_freq` | 80 … 3000 Hz, 500 … 12000 Hz, log | 420, 2400 | bell centres |
  | `eq2_gain`, `eq3_gain` | −12 … +12 dB | 0 | |
  | `eq2_q`, `eq3_q` | 0.3 … 6 | 1 | bell width |
  | `eq4_freq` | 200 … 20000 Hz, log | 20000 | high cut; 20000 reads "open" |
  | `eq1_drive` … `eq4_drive` | 0 … 1 | see below | drive of that band only |
  | `eq_sky` | 0 … 1 | 0.3 | how far activity opens the high cut (× 3 octaves) |
  **Removed:** `flt_type`, `flt_cutoff`, `flt_reso`, `flt_sky`, `drive`. Nothing has been
  released. State version bump; an older state loads with the EQ's defaults. `eq_sky` is a stopgap:
  T4.2 turns it into the route Activity → `eq4_freq` and removes the parameter.
- **`fx/Eq.h`** (header first): shelves, bells and the cut from TPT state-variable filters (the
  POC's `Svf.h` or `juce::dsp`), frequencies gliding in log (τ 20 ms, as the filter does), gains
  and widths ramped per sample. A band at 0 dB adds nothing.
- **Drive per band, in parallel:** for band *k* take the part of the signal that band owns
  (*bₖ*: below the corner for the shelf, a band-pass at the bell's centre and width for the bells,
  a band-pass an octave wide ending at the cut for band 4), saturate it with the existing ADAA
  tanh (pre-gain 1 + 8·drive, level-compensated), and add only the difference:
  `out = eq(x) + Σ driveₖ · (sat(bₖ) − bₖ)`. So zero drive is exactly the EQ alone, the harmonics
  come from that band only, and nothing has to sum back flat. If a better structure turns up, put
  it in the notes before building it.
- **The sky:** the high cut's frequency × 2^(3 · `eq_sky` · activity), activity slewed 2 s, on
  the tick grid as today.
- **Defaults and the default sound:** the EQ flat and the cut open reproduce today's open filter.
  Today's Drive (0.15, broadband) has no exact equal; start every band's drive at the value that
  brings a default render closest to today's in level and spectrum (`WorldtableRender --bands`),
  say which value, and give the owner a before/after render. Goldens change on purpose; the reason
  goes in this file.
- **Telemetry:** `eqCutHz` (the cut now, after the sky) replaces `filterHz`.
- **The page:** until T6.14, the tone module shows the EQ's parameters as plain knobs (the old
  filter picture goes) so the page and `UiCheck` keep working.
