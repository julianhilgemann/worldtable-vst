# T6.4a — UI polish (unslop pass)
**Milestone:** M6   **Depends on:** T6.1   **Branch:** feat/t6.4-ui-polish

Not the T6.4 cost pass of spec/07 (that one stays open); this is a craft pass on the T6.1 UI,
asked for by the owner on 2026-11-06 with the `unslop` skill (Damir Sokolovsky, CC BY 4.0).

## Goal
Keep everything T6.1 built (layout, palette, fonts, dome, magnetogram, every control) and fix
the craft: glow and wash on the chrome, all-caps tracked labels, too many type sizes, text
below 4.5:1, spacing off the 4 px grid, numbers that change width.

## Audit (before)
- Glow on chrome: logo drop-shadow, chord-name text-shadow, dots on the mode pill, chord pill,
  knobs and toggles, inset glow on the onset phase, glow on voicing marks and the drive dot.
- A violet radial wash across the top of the page (decoration; the dome-glow wash is spec'd and stays).
- Journey bar: violet → green gradient (decoration; the Drift arc's red → violet is spec'd and stays).
- Uppercase labels with 0.12–0.34 em tracking everywhere (caps, knob labels, phase track,
  mode, chord state, toggles, info keys, the wordmark at 600).
- 13 font sizes, 8.5–50 px; labels at 8.5–9.5 px.
- `--faint` #566079 used for text at 3.2:1.
- No `tabular-nums`.
- Paddings 10/14/8, 9/10/6, gaps 5/7/9/18/22, header 0 16 0 14.

## Direction (from the existing brand)
- Product: an ambient drone instrument that plays a recorded geomagnetic day from an Alaskan
  observatory.
- Character: nocturnal, exact, patient.
- World: an observatory at night, all-sky camera frames, magnetometer strip charts, three
  emission lines.
- Moments: the dome and the magnetogram carry the light; the voicing view carries layer colour.
- Signature: the corner-tick viewfinder frame (unchanged).

## Done
- Spacing: cards 12/16, tab modules 8/12, gaps and margins on the 4 px grid; right-column rows
  156 / 136 / 152 so the sky card and macros fit the new sizes.
- Colour: glows removed from all chrome and the voicing/drive marks; the violet wash and the
  Journey gradient gone; `--faint` → #6e7991 (4.6:1); seg radius 2 → 4.
- Copy and type: sentence case everywhere ("The sky writes", "Journey 24×", "Rate"), no wide
  tracking, scale 10 / 11 / 12 / 14 / 18 / 48, weights 400–500, `tabular-nums` on the page.
- Motion: the mode dot keeps its slow opacity breath (Journey is live), no glow.
- spec/06 updated: sentence case, the faint token, no glow on chrome.
- Round 2 (owner review, same day): no `·` separator glyphs left; fields are split by space
  (`.gap`), prose by commas, the dome legend is a small table. Nothing moves when values change:
  every live number sits in a fixed-width mono slot (`.num`, width in ch; right-aligned before a
  unit, left-aligned at the end of a field), and knob labels and values no longer size the knob.
  Checked with a probe that records element positions while the mock runs at 24× and every
  knob is swept: 0 movers (the previous commit had 10, incl. the whole header row).
